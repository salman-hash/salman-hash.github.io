An ESP32-based kitchen display system for restaurants, built at Cowlar.

## What I did

- Drove a **VGA display from an ESP32**, with the user interface built in **LVGL**.
- Integrated **MQTT** for real-time order updates.
- Added an **electronic control box** with buttons for moving the selection and updating order status.
- Built an **in-house enclosure** for deploying the complete system.
