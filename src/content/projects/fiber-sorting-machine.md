An automated optical fiber sorting machine built at Cowlar, running on an Orange Pi with Festo actuators.

## What I did

- Integrated an **ML model that detects fiber-loading errors** and other problems with the placed fibers, using OpenCV.
- Worked with the **Docker, Flask and WebSocket** stack that connects the machine to its interface.
- Joined the **quality assurance team** that moved the machine into bulk production on the line.
